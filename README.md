# 놀이온

배우는 오늘, 놀라운 모험 ON!

**게임 주소: https://kkw-web.github.io/on/**

내 이름과 캐릭터로 떠나는 학습·놀이 마을입니다. 회원가입과 나이 입력 없이 별명과 캐릭터를 고르고, 각 놀이의 난이도를 직접 선택합니다.

## 하루의 모험

1. 글자 숲: 한글·낱말 놀이에서 3문제 해결
2. 숫자 언덕: 숫자·시계·구구단 놀이에서 3문제 해결
3. 발견의 바다: 국기·규칙·협동 문제 3개 또는 기억 카드 3쌍 발견
4. 세 열쇠를 모두 모으면 그날의 ‘안녕, 토요일’ 링크가 열립니다.

도움을 받거나 다시 시도하여 해결한 문제도 인정합니다. 별을 소비하지 않으며, 완료한 날은 모험 여권에 남습니다. 미션은 이용 기기의 날짜 기준으로 매일 새로 시작합니다.

## 특별편

- **한글 잔치마당**: 제공받은 한글 윷놀이 HTML을 통합한 특별편. 한글 이야기·윷놀이·퀴즈·짝 맞추기·두더지 놀이를 포함하며 언제든 열려 있습니다.
- **안녕, 토요일**: https://kkw-web.github.io/game1/ — 그림책 속 이야기를 탐험하는 액션 게임. 새 탭에서 열립니다. 키보드·게임패드 조작 안내를 확인해 주세요.

## 저장과 공유

두 탐험가의 별명, 캐릭터, 단계, 별, 하루 미션은 현재 브라우저에 저장됩니다. 개인 정보가 포함된 공유 링크를 만들지 않습니다. 다른 기기와 자동 동기화되지 않으며 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. 공용 기기에서는 이전 탐험가의 기록이 남아 있음을 확인해 주세요.

이야기 문은 학습 동기를 위한 페이지 내 보상 장치입니다. 외부 공개 게임 URL로 직접 접속하는 것까지 차단하는 보호자 통제 기능은 아닙니다.

## 파일

- `index.html`: 놀이온 본편
- `yut.html`: 한글 잔치마당 특별편

두 파일을 같은 폴더에 배포합니다. 태블릿에서는 먼저 ‘소리 시작’을 눌러 주세요. 음성은 기기에 설치된 한국어 목소리를 기본 속도와 음높이로 사용합니다.
